E-Rechnung am offiziellen Regelwerk prüfen

Fügen Sie das XML einer E-Rechnung ein — aus einem beliebigen Plugin, aus einem beliebigen System — und sehen Sie, was das von den Behörden veröffentlichte Regelwerk tatsächlich dazu sagt.

Warum es diese Seite gibt

Die meisten WooCommerce-Rechnungs-Plugins erzeugen die Datei, mehrere tun es kostenlos. Nur wenige prüfen sie. Das Regelwerk, das über die Annahme eines Dokuments entscheidet, kompiliert zu XSLT 2.0, das PHP nicht ausführen kann — es ist also leicht, eine Rechnung zu erzeugen, die richtig aussieht und abgelehnt wird.

Wir haben unsere eigene Ausgabe vor der Veröffentlichung am offiziellen deutschen Validator gemessen, und der erste Durchlauf scheiterte an sechs seiner Regeln. Wir haben sie behoben. Diese Seite führt dieselbe Prüfung aus, auf allem, was Sie einfügen — damit Sie selbst sehen, wo Ihre Dokumente stehen.

Fragen Sie Ihr jetziges Plugin nach seinem Prüfbericht. Das ist eine faire Frage an jeden Anbieter, uns eingeschlossen — unserer liegt im Repository.

Was das hier nicht ist

Diese Seite prüft ein Dokument auf Anfrage und ist auf wenige Prüfungen pro Stunde begrenzt. Sie ist eine Demonstration, kein Dienst.

Deklera Pro ist das andere: dasselbe offizielle Regelwerk, laufend in WordPress, bei jeder Rechnung, bevor sie ausgestellt wird — damit ein Dokument, das abgelehnt würde, Ihren Shop nie verlässt. Das kostenlose Plugin erstellt die Vorabprüfung Ihrer Bestelldaten, und dort beginnen die meisten Ablehnungen.

Nichts von dem, was Sie einfügen, wird gespeichert. Das Dokument wird im Arbeitsspeicher geprüft und das Ergebnis an Ihren Browser zurückgegeben.
